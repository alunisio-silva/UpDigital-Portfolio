# UpDigital Serviços — Portfólio Web

## Publicação rápida na Vercel
1. Extraia o arquivo ZIP.
2. Entre na Vercel e escolha **Add New Project**.
3. Importe a pasta/repositório que contém `index.html` e `logo-updigital.png`.
4. Como é uma página estática, não é necessário instalar dependências.
5. Publique.

## GitHub
Você também pode criar um repositório, enviar `index.html` e `logo-updigital.png` e publicar pelo GitHub Pages.

## Arquivos
- `index.html` — página completa, responsiva e interativa.
- `logo-updigital.png` — identidade visual criada para a UpDigital Serviços.
